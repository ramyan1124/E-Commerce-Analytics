# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes e-commerce sales and customer data to identify revenue trends, product performance, customer behavior, and business insights.

The project uses SQL for data analysis and Power BI for interactive dashboard development.

## 🎯 Business Objectives

- Analyze overall sales and revenue performance
- Identify top-performing products
- Understand customer purchasing behavior
- Analyze repeat customers
- Compare sales across categories and states
- Identify monthly revenue trends
- Analyze payment methods and order status

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Power BI
- DAX
- CSV
- Excel

## 📂 Dataset

The dataset contains:

- 1,000 customers
- 25 products
- 6,000 orders
- 8,126 order items
- Data period: January 2025 – June 2026

### Dataset Files

- `customers.csv`
- `products.csv`
- `orders.csv`
- `order_items.csv`

## 📈 Key Insights

- Delivered orders were used as the primary basis for revenue and customer analysis.
- The business generated approximately ₹8.33 crore in delivered revenue.
- Returning customers represented approximately 97.59% of customers with at least one delivered order.
- The dashboard enables analysis of product, customer, geographic, payment, and monthly performance.
